Media Pembelajaran Interaktif IPAS

Materi: Wujud Zat dan Perubahannya (Fase B Kelas IV SD/MI)

🎯 Sasaran & Capaian Pembelajaran

Dirancang khusus untuk siswa Sekolah Dasar / Madrasah Ibtidaiyah Kelas IV usia 9–10 tahun sesuai Capaian Pembelajaran (CP) Kurikulum Merdeka IPAS Phase B. Siswa diajak mengenali wujud zat (padat, cair, gas), mengidentifikasi sifat-sifatnya, serta menganalisis 6 jenis perubahan wujud zat dalam kejadian sehari-hari.

👨‍💻 Pengembang Media

Pengembang: **Tim Media Pembelajaran Interaktif SD/MI**

Teknologi: HTML5, CSS3 (Tailwind CSS), Vanilla JavaScript ES6, Responsive Web Design.
